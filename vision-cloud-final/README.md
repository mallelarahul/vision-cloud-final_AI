## 🚀 Getting Started

### Run Locally

1. Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/vision-cloud.git
```

2. Open in VS Code
```bash
cd vision-cloud
code .
```

3. Right-click `index.html` → **Open with Live Server**

> No npm, no build step, no dependencies needed!

---

## 🌍 Deployment

### Netlify (Recommended)
1. Push code to GitHub
2. Go to [netlify.com](https://netlify.com) → New Site → Import from Git
3. Select this repo → leave build settings blank → **Deploy**

### Vercel
1. Go to [vercel.com](https://vercel.com) → New Project → Import from Git
2. Select this repo → **Deploy**

### GitHub Pages
1. Go to repo **Settings** → **Pages**
2. Source: `main` branch → `/root`
3. Save → live at `https://YOUR_USERNAME.github.io/vision-cloud`

## 🎨 Customization

### Change Colors
Open `styles.css` and edit the `:root` variables:
```css
:root {
    --accent-terracotta: #d97706;  /* Main accent */
    --accent-gold: #f59e0b;        /* Secondary accent */
    --accent-rose: #f43f5e;        /* Highlight color */
}
```

### Change Content
Open `index.html` and edit text inside `<h1>`, `<h2>`, `<p>` tags directly.

### Change Address / Contact
Search for `12800 Westridge Blvd` in `index.html` and update both instances (footer + contact modal).
